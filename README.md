
### 1. Clone the repo:
```
git clone https://github.com/lehibonafe/docker-ecs-fargate-cicd.git
cd node-fargate-app
```

### 2. Install dependencies:
```
npm install
```

### 3. Start server
```
npm start
```

### 4. Open browser
```
http://localhost:3000
```
